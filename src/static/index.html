麦克风与隐私

浏览器需要 HTTPS 或 localhost 才能使用麦克风。点击开始后，音频会发送到服务器；输入音频与转写可能被保存。结束会释放麦克风，清空页面记录不会删除服务器文件。

当前为 ActorEngine 研究演示，具体策略以上方配置为准。首文本／首音频到达从回复开始事件计时；①②③另计服务器等待与生成。转写及回复文本不代表实际已听到的音频前缀；指标不作为正式评测分数，也不是嘴停到扬声器出声延迟。逐轮事件、文本及浏览器性能指标会保存在服务器，清空页面不会删除它们。服务未内置公网鉴权，建议仅通过 SSH 转发展示。
